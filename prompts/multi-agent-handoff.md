# Prompt: Multi-agent handoff

Use this when handing work from one agent or mode to another.

```text
Prepare a handoff note in `.planning/current/notes.md`.

Keep using the persona selected for the work being handed off. Name that persona in the handoff so the next agent can either continue it or explicitly select the persona for its next role.

Include:

- current state
- completed work
- remaining work
- known risks
- commands already run
- commands still needed
- files likely needing attention
- suggested next step

Do not overwrite existing notes. Add a new handoff section.
```
